# User journey

1. Add a URL, media, or pasted content, with a manual fallback.
2. Inspect Content DNA and intended audience context.
3. Watch the live room move through exposure, attention, interpretation, decision,
   and action.
4. Review simulated outcomes, segment disagreements, and their evidence.
5. Apply an evidence-tied Version B.
6. Re-simulate Version B against the preserved audience and compare simulated change.
