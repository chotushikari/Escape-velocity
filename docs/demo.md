# Velloe demo mode

The no-key demo uses deterministic content and a deterministic audience.

The in-product controller progresses through `INTRO → CONTENT → DNA → AUDIENCE →
SIMULATION → INSIGHTS → STRATEGY → VERSION B → RE-SIMULATION → COMPARISON →
COMPLETE`. It can be paused, advanced, restarted, or jumped to a stage during a
judge presentation. All fixture outcomes are clearly synthetic hypotheses, not
observed Velloe performance. A verified Velloe URL and permitted source copy can be
substituted later; none was supplied with this repository.

- 0–10s: show the Velloe post
- 10–20s: Content DNA
- 20–35s: audience
- 35–50s: room live
- 50–62s: intelligence
- 62–73s: Version B
- 73–88s: same-audience re-simulation
- 88–90s: simulated before/after comparison
